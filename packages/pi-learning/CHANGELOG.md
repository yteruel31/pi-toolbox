## [Unreleased]

### Added
- Initial `pi-learning` package for session-scoped, pull-only technical learning.
- `/learn` command with subcommand and journal autocompletion.
- Guided topic and concrete-outcome activation, status, verbatim notes, pause, and explicit Markdown resume.
- Branch-aware Pi session checkpoints and append-only provenance-labeled journals.
- Challenge-first tutor prompt with official-source research, roadmap.sh secondary checks, graduated hints, artifact-plus-explanation mastery, and a novel transfer challenge.
- Constrained `learning_journal` tool for AI-authored sources, checkpoints, hints, mastery evidence, and completion.
- Built-in `edit` and `write` blocking while learning mode is active.
- A paired `learning/<topic-slug>/` learner workspace that the tutor can inspect directly, avoiding copy-pasted exercise files.
